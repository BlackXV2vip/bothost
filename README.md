# 🤖 بوت هوست — استضافة بوتات بايثون عن طريق تليجرام

بوت تليجرام بيستضيف بوتات بايثون تانية: تبعتله ملف `.py` وهو بيثبّت المكتبات تلقائياً ويشغّله ويديك أزرار تحكم كاملة — كله من جوه تليجرام.

**البوت:** @YourBot (هيتحدد لما تحط التوكن)

## 📌 إزاي تستخدمه؟

1. ابعت للبوت ملف `.py` فيه كود بوتك
2. **البوت بيقرا الكود ويكتشف المكتبات المطلوبة تلقائياً** 🔍
3. تدوس زرار **«📦 ثبّتها وشغّل»** — مرة واحدة وفيثبّت كل حاجة ويشغّل بوتك
4. تتحكم بأزرار: ▶️ تشغيل • ⏹ إيقاف • 📜 اللوج • ♻️ إعادة تثبيت • 🗑 حذف

**أوامر إضافية:** `/mybots` (بوتاتك) • `/id` (رقمك) • `/help`

## 🛡️ الحماية والحدود

| الحد | القيمة |
|---|---|
| ذاكرة كل بوت مستضاف | 150 ميجا (بيتوقف تلقائياً لو عدّاها) |
| أقصى مدة تثبيت مكتبات | 5 دقايق |
| عدد البوتات الكلي | 3 (متغير `MAX_BOTS`) |
| بوتات لكل مستخدم | 2 |
| حجم الملف | 1 ميجا |
| الرفع | للأدمن بس (أو الكل لو `OPEN_UPLOADS=true`) |

- توكن البوت المضيف **بيتشال** من بيئة أي بوت مستضاف (عزل)
- البوتات بتتراقص لوحدها لو السيرفر أعيد تشغيله
- أول واحد يكلّم البوت بيبقى **الأدمن** تلقائياً (أو حط `ADMIN_IDS`)

## 🚀 النشر على Render

- **Runtime:** Python
- **Build:** `pip install -r requirements.txt`
- **Start:** `python bot.py`
- **متغيرات البيئة:**
  - `BOT_TOKEN` — توكن البوت من @BotFather (إجباري)
  - `ADMIN_IDS` — أرقام الأدمنز بفاصلة (اختياري — الأول تلقائياً بيبقى أدمن)
  - `MAX_BOTS` — أقصى عدد بوتات (افتراضي 3)
  - `OPEN_UPLOADS` — `true` يسمح للكل بالرفع (افتراضي للأدمن بس)

البوت بيحافظ على نفسه صاحي على الخطة المجانية بـ self-ping كل 10 دقايق.

## ⚠️ ملاحظات مهمة

- **ملفات البوتات بتتخزن على السيرفر** — والخطة المجانية في Render بتمسح الملفات عند إعادة النشر (يعني البوتات المستضافة هتحتاج رفع تاني بعد أي تعديل على كود البوت المضيف). الحل المدفوع: إضافة Disk
- البوتات المستضافة لازم تبدأ تنفيذ على طول — الملف بيتنفذ مش بيستنى
- دي منصة شخصية (ليك ولمعارفك) — مش معمولة عزل كامل لمستخدمين مجهولين

## 💻 التشغيل المحلي

```bash
pip install -r requirements.txt
BOT_TOKEN=توكنك python bot.py
```
