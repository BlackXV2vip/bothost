# 🤖 بوت هوست v3 — منصة استضافة بوتات بايثون عن طريق تليجرام

منصة كاملة: تبعت ملف بوت (أو مشروع zip كامل) والمضيف يكتشف المكتبات، يثبتهم، يشغّل، ويديك لوحة تحكم كاملة — مع تخزين دائم على GitHub.

**البوت:** @Python_Hos_ting_bot

## ✨ مميزات v3

- 🖥 **لوحة تحكم للأدمن** (`/panel`): إحصائيات حية، كل البوتات، معلومات النظام والذاكرة، صيانة، وإذاعة للمستخدمين
- 📦 **دعم مشاريع zip كاملة** — ملفات متعددة (كود + config + requirements) بمحلل آمن
- 🔍 **اكتشاف المكتبات تلقائي** من الكود (70+ مكتبة شائعة) وزرار تثبيت واحدة
- 🎛 تحكم كامل لكل بوت: تشغيل/إيقاف/إعادة تشغيل/لوج حي/إعادة تثبيت/حذف
- ☁️ **تخزين دائم**: البوتات على ريبو خاص بترجع لوحدها بعد أي إعادة نشر
- 🔐 عزل أسرار + حقن `ADMIN_ID` تلقائي لبوتات المستخدمين + حدود موارد لكل بوت
- 📡 self-ping للبقاء صاحي + استئناف البوتات الشغالة تلقائياً

## 📌 الأوامر

| أمر | الوظيفة |
|---|---|
| `/mybots` | بوتاتك مع أزرار التحكم |
| `/panel` | 🖥 لوحة تحكم الأدمن |
| `/help` | الدليل الكامل |
| `/id` | رقمك على تليجرام |

## ⚙️ الحدود (متغيرات البيئة)

| المتغير | افتراضي | الوظيفة |
|---|---|---|
| `MAX_BOTS` | 8 | إجمالي البوتات المستضافة |
| `MAX_RUNNING` | 4 | أقصى بوتات شغالة مع بعض (حد ذاكرة السيرفر) |
| `PER_USER` | 3 | بوتات لكل مستخدم |
| `BOT_TOKEN` | إجباري | توكن البوت من BotFather |
| `ADMIN_IDS` | — | أرقام الأدمنز (الأول تلقائياً) |
| `GH_PERSIST_TOKEN` / `GH_PERSIST_REPO` | — | التخزين الدائم على GitHub |

## 🚀 النشر على Render

- **Runtime:** Python • **Build:** `pip install -r requirements.txt` • **Start:** `python bot.py`
- Health check: `/healthz`

## ⚠️ ملاحظات

- ذاكرة السيرفر على الخطة المجانية 512MB — عشان كده فيه حد للتشغيل المتوازي
- ملفات البوتات بتتراقص من القرص المؤقت، لكن بتترجع تلقائياً من السحابة
- منصة شخصية/للمعارف — مش معزولة لمستخدمين مجهولين بالكامل
